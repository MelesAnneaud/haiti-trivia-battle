# Haiti Trivia Battle

🇭🇹 A multiplayer Haiti trivia game.

## About

Haiti Trivia Battle is a fun game where players answer questions about Haiti and compete for the highest score.

## Features

- 🇭🇹 Haiti history and culture questions
- 👥 Two-player competition
- 🏆 Scoreboard
- ❓ Multiple-choice questions
- 📱 Designed to work on phones and computers

## How to Play

1. Enter your name.
2. Join the game.
3. Answer the trivia questions.
4. Earn points for correct answers.
5. The player with the highest score wins!
